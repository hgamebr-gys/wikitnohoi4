# Wiki TNO (site estático)

Este repositório contém um site estático da wiki de *Hearts of Iron IV: The New Order* (TNO) em português.

## Estrutura

- `index.html`: página inicial da wiki.
- `pages/`: páginas internas (linha do tempo, nações, mecânicas, glossário, roadmap).
- `styles.css`: estilos globais.

## Como visualizar localmente

```bash
python -m http.server 8000
```

Depois, acesse `http://localhost:8000` no navegador.
